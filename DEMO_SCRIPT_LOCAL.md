# Local demonstration script

Follow [the startup guide](DEMO_GUIDE.md). The previous script is preserved in
[the historical copy](docs/plans/DEMO_SCRIPT_LOCAL.pre-A2-2026-11-01.md).
Do not clear historical evidence before demonstrating the application.

**Explain the task.** ?An actual support ticket flows through classification,
KB retrieval, a customer reply and a background summary. The scheduler can choose
model, destination and start time under explicit quality/deadline constraints.?

**Show the queue.** Select fixed assignment and queue a fictional ticket.
?The page saves work. A separate worker runs eligible steps, retains outputs
across restarts and never automatically repeats an ambiguous provider call.?
Run inference only when the exact configured models and endpoint are available.
Otherwise show stored evidence and state the limitation.

**Show optimized rejection.** Select optimized policy and actual frozen profiles.
?These profiles lack human semantic review, so the system retains infeasibility
instead of guessing quality. The UI does not probe providers; the worker checks
availability.? Expand decision history, rejected alternatives and missing inputs.

**Show evidence.** Load a validated evaluation/comparison.
?The table retains unsuccessful and unfinished denominators. Unknown metrics
stay unknown. Zero API cost has no savings percentage. CO2 and CO2e are distinct.?
A prepared pilot with zero completed trials is not experimental results.

**Show review.** On a reviewable trial, inspect the frozen KB and actual outputs.
?A human supplies every score and rationale. The score is the weakest step mean,
with a criterion floor. Approvals bind exact evidence and cannot be replaced.?
Do not enter judgments unless the actual reviewer has assessed the evidence.

**State the boundary.** ?The local software integrates execution, accounting,
policy evaluation, human-review imports and strict replay. Full A2 validation
still requires real reviews, a second confirmed destination and final controlled
live measurements. No measured savings are claimed.?
